01 — OVERVIEW

Answering questions with university-specific information.

I developed and deployed a conversational AI chatbot to answer prospective student queries using ITM University-specific PDF and document data.

The project uses LangChain for LLM workflow orchestration, custom prompt engineering, and LangGraph for workflow and state management. It is deployed using Streamlit Community Cloud.

02 — APPROACH & FEATURES

A focused conversational workflow.

  • Conversational interface for prospective student questions
  • University-specific PDF and document data as the information source
  • LLM workflow orchestration with LangChain
  • Workflow and state management with LangGraph
  • Custom prompts and a Streamlit application interface

03 — WHAT I BUILT & LEARNED

Connecting language models to an application.

I brought together document-based university information, prompt design and an orchestrated LLM workflow in a deployable Streamlit application. This gave me hands-on practice with LangChain, LangGraph and building an end-to-end Generative AI interface.
