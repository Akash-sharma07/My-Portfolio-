Flight Database

An end-to-end application to extract, process and explore flight-related data from a MySQL database.

IN THIS PROJECT

OverviewApproachWhat I learned

01 — OVERVIEW

Exploring flight-related data from a database.

I built an end-to-end application to extract, process and analyze flight-related data stored in a MySQL database using SQL and Pandas.

An interactive Streamlit interface lets users explore and present the analyzed data.

02 — APPROACH & FEATURES

Database queries, data processing and an interactive interface.

  • Connects to a MySQL database with PyMySQL
  • Uses SQL to extract flight-related records
  • Processes and analyzes data with Pandas
  • Provides an interactive Streamlit interface for exploration and presentation

03 — WHAT I BUILT & LEARNED

Working across the data workflow.

This project brought database access, SQL queries, data processing and an interactive application together. It gave me practice in connecting a Python application to MySQL and presenting data through Streamlit.
