02 / RECOMMENDER SYSTEMS

Recommendify

A book and movie recommendation platform that brings content-based and collaborative recommendation approaches into one Flask application.

PROJECT TYPEBook & movie recommenders
BUILT WITHPython · Pandas · Scikit-learn · Flask
DATA / APITMDB 5000 dataset · TMDB API

IN THIS PROJECT

OverviewApproachWhat I learned

01 — OVERVIEW

Book and movie recommendations in one place.

Recommendify combines a TF-IDF and cosine-similarity book recommender with an existing collaborative filtering model in a Flask application. It also includes a content-based movie recommender built with the TMDB 5000 dataset.

02 — APPROACH & FEATURES

Combining recommendation approaches.

  • Combines a TF-IDF and cosine-similarity book recommender
  • Includes an existing collaborative filtering model
  • Builds a content-based movie recommender using TMDB 5000 metadata
  • Uses genre, cast, director and keywords in movie metadata
  • Unifies the recommenders in a Flask application with Jinja2 templates
  • Fetches movie posters using the TMDB API

03 — WHAT I BUILT & LEARNED

Bringing separate models together.

I integrated book and movie recommendation components into one application and worked with text features, similarity, movie metadata, template rendering and poster fetching through an API.
