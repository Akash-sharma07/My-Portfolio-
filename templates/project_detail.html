AI Admissions
Chatbot

ITM University Gwalior · A conversational assistant for prospective student queries, grounded in university-specific PDF and document data.

PROJECT TYPEConversational AI
BUILT WITHPython · LangChain · LangGraph · Streamlit
DEPLOYMENTStreamlit Community Cloud

IN THIS PROJECT

OverviewApproachWhat I learned

01 — OVERVIEW

Answering questions with university-specific information.

I developed and deployed a conversational AI chatbot to answer prospective student queries using ITM University-specific PDF and document data.

The project uses LangChain for LLM workflow orchestration, custom prompt engineering, and LangGraph for workflow and state management. It is deployed using Streamlit Community Cloud.

02 — APPROACH & FEATURES

A focused conversational workflow.

  • Conversational interface for prospective student questions
  • University-specific PDF and document data as the information source
  • LLM workflow orchestration with LangChain
  • Workflow and state management with LangGraph
  • Custom prompts and a Streamlit application interface

03 — WHAT I BUILT & LEARNED

Connecting language models to an application.

I brought together document-based university information, prompt design and an orchestrated LLM workflow in a deployable Streamlit application. This gave me hands-on practice with LangChain, LangGraph and building an end-to-end Generative AI interface.

02 / RECOMMENDER SYSTEMS

Recommendify

A book and movie recommendation platform that brings content-based and collaborative recommendation approaches into one Flask application.

PROJECT TYPEBook & movie recommenders
BUILT WITHPython · Pandas · Scikit-learn · Flask
DATA / APITMDB 5000 dataset · TMDB API

IN THIS PROJECT

OverviewApproachWhat I learned

01 — OVERVIEW

Book and movie recommendations in one place.

Recommendify combines a TF-IDF and cosine-similarity book recommender with an existing collaborative filtering model in a Flask application. It also includes a content-based movie recommender built with the TMDB 5000 dataset.

02 — APPROACH & FEATURES

Combining recommendation approaches.

  • Combines a TF-IDF and cosine-similarity book recommender
  • Includes an existing collaborative filtering model
  • Builds a content-based movie recommender using TMDB 5000 metadata
  • Uses genre, cast, director and keywords in movie metadata
  • Unifies the recommenders in a Flask application with Jinja2 templates
  • Fetches movie posters using the TMDB API

03 — WHAT I BUILT & LEARNED

Bringing separate models together.

I integrated book and movie recommendation components into one application and worked with text features, similarity, movie metadata, template rendering and poster fetching through an API.
